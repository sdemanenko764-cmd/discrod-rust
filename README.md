# Rustcord — лёгкий клиент Discord на Rust

Нативное приложение вместо официального клиента. Подключается к настоящему Discord: твои серверы, каналы и личка, но без встроенного браузера внутри.

## Почему ест меньше памяти

Официальный Discord сделан на Electron: внутри каждого окна работает целый Chromium плюс Node.js, поэтому он обычно занимает сотни мегабайт. Rustcord устроен как оптимизационные моды для Minecraft — убирает тяжёлое и держит в памяти только нужное:

- **Нет браузерного движка.** Интерфейс рисуется библиотекой egui прямо через OpenGL, это один небольшой процесс.
- **Только нужные данные.** Из ответов Discord берутся id, имена, тексты и время. Аватары, роли, эмодзи, настройки и прочее отбрасываются ещё при разборе и в память не попадают.
- **Лимиты кэша.** Сообщения хранятся максимум для 6 последних открытых каналов, до 200 на канал. Старые каналы выгружаются и подгружаются заново при открытии. Константы `MAX_CACHED_CHANNELS` и `MAX_MESSAGES_PER_CHANNEL` в `src/main.rs`.
- **Без картинок.** Вложения показываются как `[файл: имя]`, изображения не скачиваются.
- **Не грузит процессор в простое.** Окно перерисовывается только при новых событиях.
- **Индикатор ОЗУ** внизу окна, как F3 в майнкрафте: видно, сколько занимает клиент и сколько сообщений в кэше.

Точная цифра зависит от видеодрайвера и количества серверов: проверь сам по индикатору и сравни с Discord в диспетчере задач (у Discord сложи все его процессы).

## Что умеет

- Вход по токену бота или аккаунта, с запоминанием сессии
- Список серверов, каналы по категориям в том же порядке, что в Discord
- Личные сообщения и группы
- Чтение истории с подгрузкой более ранних сообщений
- Отправка сообщений (Enter)
- Новые, изменённые и удалённые сообщения в реальном времени
- Метки непрочитанного на серверах и каналах
- Автоматическое переподключение

Пока нет: голосовых каналов, картинок, реакций, ответов на сообщения, редактирования своих сообщений, уведомлений. Голос — отдельный большой этап (протокол Discord Voice + кодек Opus).

## ⚠ Важно про аккаунт

- **Токен бота** — полностью разрешено Discord. Бот видит только те серверы, куда ты его добавил.
- **Токен своего аккаунта** — сторонние клиенты нарушают правила Discord, аккаунт могут заблокировать. Решение за тобой. Если хочешь попробовать без риска, начни с бота или второго аккаунта.
- Никому не передавай токен: с ним входят в аккаунт без пароля. Rustcord хранит его только локально, в `%APPDATA%\Rustcord\session.txt`; кнопка «Выйти» удаляет файл.

Где взять токен — подробно расписано прямо на экране входа (раскрывающиеся подсказки).

## Как получить rustcord.exe

### Вариант 1: собрать у себя (Windows)
1. Распакуй архив.
2. Дважды кликни **`build-windows.bat`**.
3. Если Rust не установлен, откроется rustup.rs: установи (если предложит Visual Studio Build Tools — соглашайся) и снова запусти `build-windows.bat`.
4. Через 2–5 минут рядом появится **`rustcord.exe`**, и он сразу запустится.

Дальше просто запускай `rustcord.exe`. Его можно перенести куда угодно, это один файл.

### Вариант 2: собрать в облаке, ничего не устанавливая
1. Создай репозиторий на GitHub и загрузи туда содержимое этой папки.
2. Вкладка **Actions** — сборка запустится сама.
3. Через ~5–10 минут скачай `rustcord.exe` из раздела **Artifacts**.

### Linux / macOS
```bash
# Linux: sudo apt install build-essential pkg-config libssl-dev
cargo run --release
```

## Устройство

```
src/
├── main.rs      интерфейс на egui, состояние, кэш с лимитами
├── discord.rs   Gateway (WebSocket) + REST API, разбор в компактные структуры
└── store.rs     сохранение сессии
```

Сеть работает в отдельном потоке с однопоточным tokio-рантаймом, интерфейс — в главном. Они общаются через каналы команд и событий, поэтому окно не подвисает, пока что-то грузится.

## Частые проблемы

- **«Токен недействителен»** — токен скопирован не полностью или сброшен. Возьми новый.
- **Бот видит каналы, но сообщения пустые** — включи *Message Content Intent* у бота в Developer Portal.
- **«Нет доступа к этому каналу»** — у аккаунта или бота нет прав на чтение этого канала (каналы показываются все, права не проверяются заранее).
- **Сборка падает с `link.exe not found`** — не установлены Visual Studio Build Tools (компонент «Разработка классических приложений на C++»).
